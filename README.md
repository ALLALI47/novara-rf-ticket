# 🎟️ ɴᴏᴠᴀʀᴀ ʀғ ᴛɪᴄᴋᴇᴛ - بوت التيكت المتطور

بوت تيكت احترافي مصمم خصيصاً لسيرفر FiveM / Roleplay **ɴᴏᴠᴀʀᴀ ʀғ**.

---

## 🌟 مميزات البوت (Features)

1. **نظام الرومات الخاصة (Strict Private Channels)**:
   - عند فتح أي تيكت، يتم إنشاء روم خاصة تمنع رؤيتها عن باقي الأعضاء (`@everyone` مخفي بالكامل).
   - لا يمكن لأحد رؤية التيكت إلا: **الشخص الذي فتح التيكت**، **البوت**، و**طاقم الإدارة المختص (Staff)**.

2. **دعم كامل لـ 12 فئة تيكت (12 Ticket Categories)**:
   - 💠 `Partner` (شراكة)
   - 👑 `VIP` (خدمات كبار الشخصيات)
   - 🚨 `Need Help` (مساعدة عامة)
   - 👑 `Need High Staff` (الإدارة العليا)
   - 💵 `Need Refund` (استرجاع)
   - 👨‍💻 `Need Développer` (فريق التطوير والمشاكل البرمجية)
   - 🛠️ `Report Player` (إبلاغ عن لاعب)
   - 🛠️ `Report Bug` (إبلاغ عن خطأ باللعبة)
   - 👾 `Streamer Request` (طلبات الستريمرز)
   - 🎬 `Propose Scène & Event` (اقتراح فعاليات وسيناريوهات RP)
   - 📝 `Change Name & Lost Character` (تغيير اسم أو استرجاع شخصية)
   - 🔓 `Remove Ban & Warn` (طلب فك الباند أو إزالة التحذيرات)

3. **توجيه تلقائي للتصنيفات واللوقات (Auto-Routing & Logging)**:
   - يتم إنشاء التيكت داخل الكاتيجوري المناسب في الديسكورد (مثلاً `🎟️ 𝐕𝐈𝐏` لتيكت VIP).
   - عند إغلاق التيكت، يتم حفظ سجل المحادثة (Transcript HTML احترافي بتصميم ديسكورد المظلم) وإرساله مباشرة إلى الروم المخصص في كاتيجوري `⊰───────⋅ Tickets Log ⋅───────⊱` (مثل `📋〡vip` أو `📋〡need-help`).
   - إرسال نسخة من سجل المحادثة إلى الخاص (DM) لصاحب التيكت.

4. **أزرار تحكم تفاعلية (Interactive Buttons)**:
   - 🔒 **Fermer / إغلاق**: مع نافذة تأكيد لمنع الإغلاق بالخطأ وعد تنازلي (5 ثوانٍ) قبل الحذف.
   - 📌 **Claim / استلام**: يتيح للمشرف استلام التيكت وتنبيه باقي الإدارة.
   - 👥 **Ajouter / إضافة عضو**: نافذة منبثقة (Modal) لإضافة صديق أو طرف آخر للتيكت.
   - 📜 **Transcript / نسخ المحادثة**: حفظ وتنزيل ملف المحادثة بصيغة HTML فوراً.

5. **نظام تقديم الستاف (Staff Recruitment System)**:
   - تم نشر بانل التقديم في روم `👷┃staff・apply`.
   - عند الضغط على زر `📝 Apply` تظهر نافذة الاستمارة الرسمية (Application Form) المكونة من 5 أسئلة:
     1. `Name : *`
     2. `Age : *`
     3. `Expérience : *`
     4. `Activity : *`
     5. `Why should we accept you ? : *`
   - عند الإرسال، يُنشئ البوت روم اختبار خاصة للمترشح تحت كاتيجوري `🎟️𝐑𝐄𝐂 𝐒𝐓𝐀𝐅𝐅 𝐓𝐈𝐂𝐊𝐄𝐓`.
   - تظهر للمسؤولين أزرار للقرار:
     - `✅ Accepter pour Test`: يمنح المترشح رتبة `Waiting To Test` تلقائياً ويرسل له إشعار القبول.
     - `❌ Refuser`: يرسل للمترشح رسالة اعتذار رسمية.
     - `🔒 Fermer`: إغلاق الروم وحفظ الأرشيف.
   - إرسال تقرير فوري بكل تقديم جديد إلى روم `🗒️・staff・apply・log`.

6. **تصميم سينمائي فخم (Design Aesthetics)**:
   - تم تصميم بانر ثلاثي الأبعاد خاص بـ `NOVARA RF - FIVEM ROLEPLAY TICKET SYSTEM`.

## 🚀 طريقة التشغيل (How to Run)

### الطريقة السهلة (Windows):
اضغط مرتين على ملف **`start.bat`** وسيقوم بتشغيل البوت تلقائياً!

### أو عبر الطرفية (Terminal):
```bash
npm start
```

---

## ⚙️ أوامر السلاش (Slash Commands)

- `/setup-ticket [channel]` : إرسال بانل التيكت الرسمي في أي روم تختاره.
- `/ticket-add <utilisateur>` : إضافة عضو إلى التيكت.
- `/ticket-remove <utilisateur>` : إزالة عضو من التيكت.
- `/ticket-rename <nom>` : إعادة تسمية روم التيكت.
- `/ticket-close [raison]` : إغلاق التيكت مع تحديد السبب.

---

## 📁 ملفات المشروع (File Structure)

- `index.js` : نقطة البداية وتشغيل البوت وتسجيل الأوامر.
- `config.js` : إعدادات السيرفر، الرتب، الكاتيجوريات وروابط اللوقات.
- `database.js` : نظام تخزين وحفظ أرقام التيكت وحالاتها.
- `transcript.js` : محرك إنشاء ملفات الـ HTML الفخمة للـ Transcripts.
- `handlers/ticketCreate.js` : معالج فتح التيكت وضبط الصلاحيات الصارمة.
- `handlers/ticketActions.js` : معالج الأزرار (إغلاق، استلام، إضافة عضو).
- `commands/ticketCommands.js` : تسجيل ومعالجة أوامر السلاش.
- `deploy-panel.js` : سكريبت فوري لنشر البانل بضغطة زر.
- `banner.jpg` : الصورة الرسمية لبانل التيكت.
